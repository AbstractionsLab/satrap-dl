# Incident endpoint class diagram

The diagram below shows the classes, functions, and data models involved in the `POST /incident/{alert_type}` request.

Note that a refactoring is already foreseen, to remove the need for an alert type string in the endpoint path and instead provide an optional template name or ID as part of the request body. This would allow decoupling the incident creation logic from the analysis scenarios.

```mermaid
classDiagram
    direction TB

    %% ── API layer ─────────────────────────────────────────────────────────

    class `api.py` {
        <<FastAPI application>>
        +create_incident(alert_type: str, incident: IncidentRequest) IncidentResponse
    }

    %% ── Pydantic models ───────────────────────────────────────────────────

    class IncidentRequest {
        <<Pydantic BaseModel>>
        +score: float  [0.0..1.0]
        +title: str | None
        +model_extra: dict  [extra fields allowed]
    }

    class IncidentResponse {
        <<Pydantic BaseModel>>
        +id: int
        +link: str
    }

    %% ── Service layer ─────────────────────────────────────────────────────

    class `incident_service.py` {
        <<module>>
        +create_incident_case(alert_type: str, incident: IncidentRequest) IncidentResponse
    }

    %% ── Settings ──────────────────────────────────────────────────────────

    class AnalysisScenario {
        <<Enum>>
        SUSPICIOUS_LOGIN
    }

    class RuntimeSettings {
        <<dataclass>>
        +enable_misp_search: bool
        +enable_case_creation: bool
        +priority_thresholds: dict[str, float]
    }

    class `runtime_settings.py` {
        <<module>>
        +load_decipher_runtime_cfg() RuntimeSettings
    }

    %% ── Case management layer ─────────────────────────────────────────────

    class `flowintel_connector.py` {
        <<module>>
        +create_case_from_bundle(scenario: AnalysisScenario, case_bundle: IncidentRequest) int
        -_assign_priority_tag(score: float) str
        -_map_tier_to_tag(tier: str) str
        -_format_incident_body(data: dict) str
        -_create_case_without_template(client, scenario, payload) int
        -_create_case_with_template(client, template_id, payload) int
    }

    class CaseTemplate {
        <<frozen dataclass>>
        +title: str
        +filename: str
    }

    class `template_catalog.py` {
        <<module>>
        +CASE_TEMPLATES: dict[AnalysisScenario, CaseTemplate]
    }

    %% ── Exceptions ────────────────────────────────────────────────────────

    class CaseCreationError {
        <<Exception>>
    }

    class UnavailablePyFlowintelError {
        <<Exception>>
    }

    %% ── External dependency ───────────────────────────────────────────────

    class PyFlowintel {
        <<external: pyflowintel>>
        +from_config(path: str) PyFlowintel
        +cases.create(title, **payload) dict
        +templates.create_case_from_template(template_id) dict
        +cases.update(case_id, payload) void
    }

    %% ── Relationships ─────────────────────────────────────────────────────

    `api.py`                  ..>  IncidentRequest          : validates body
    `api.py`                  ..>  IncidentResponse         : returns
    `api.py`                  -->  `incident_service.py`    : delegates
    `api.py`                  ..>  CaseCreationError        : catches → 500

    `incident_service.py`     ..>  AnalysisScenario         : maps alert_type
    `incident_service.py`     -->  `flowintel_connector.py` : calls create_case_from_bundle()
    `incident_service.py`     ..>  IncidentResponse         : builds and returns
    `incident_service.py`     ..>  CaseCreationError        : raises / propagates

    `flowintel_connector.py`  -->  `runtime_settings.py`    : load_decipher_runtime_cfg()
    `flowintel_connector.py`  ..>  RuntimeSettings          : reads priority_thresholds
    `flowintel_connector.py`  -->  `template_catalog.py`    : looks up CASE_TEMPLATES
    `flowintel_connector.py`  ..>  CaseTemplate             : uses title / filename
    `flowintel_connector.py`  -->  PyFlowintel              : HTTP REST calls
    `flowintel_connector.py`  ..>  UnavailablePyFlowintelError : raises on config error
    `flowintel_connector.py`  ..>  CaseCreationError        : raises on API error

    `template_catalog.py`     "1" *-- "0..*" CaseTemplate   : contains
    `runtime_settings.py`     ..>  RuntimeSettings          : instantiates
```
