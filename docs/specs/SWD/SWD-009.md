# Incident endpoint flow

The diagram below details the full request lifecycle of `POST /incident/{alert_type}`, including required validations and error paths.

```mermaid
sequenceDiagram
    actor Client as Client
    participant API as api.py (FastAPI)
    participant IncidentSvc as incident_service.py
    participant FlowConn as flowintel_connector.py
    participant TemplateCatalog as template_catalog.py
    participant RuntimeCfg as runtime_settings.py
    participant Flowintel as Flowintel

    Client->>API: POST /api/v0.1/incident/{alert_type} {score, title, extra fields}

    note over API: Pydantic validates score in [0,1] and request body
    alt score outside [0,1] or malformed body
        API-->>Client: 422 Unprocessable Entity with validation error
    end

    API->>IncidentSvc: create_incident_case(alert_type, IncidentRequest)

    note over IncidentSvc: Map alert_type to AnalysisScenario enum
    alt alert_type not in AnalysisScenario
        IncidentSvc-->>API: ValueError (unknown alert type)
        API-->>Client: 404 Not Found
    end

    IncidentSvc->>FlowConn: create_case_from_bundle(scenario, case_bundle)

    FlowConn->>RuntimeCfg: load_decipher_runtime_cfg()
    RuntimeCfg-->>FlowConn: priority_thresholds

    note over FlowConn: Map score to priority tag using thresholds
    FlowConn->>FlowConn: _assign_priority_tag(score)

    FlowConn->>TemplateCatalog: lookup CASE_TEMPLATES[scenario]
    TemplateCatalog-->>FlowConn: CaseTemplate (title, filename) or none

    FlowConn->>FlowConn: _format_incident_body(extra fields)
    note over FlowConn: Format non-score metadata into case description

    FlowConn->>Flowintel: POST /cases/create (title, description, tags=[priority_tag])

    alt Flowintel API error or connection failure
        Flowintel-->>FlowConn: error
        FlowConn-->>IncidentSvc: CaseCreationError
        IncidentSvc-->>API: CaseCreationError
        API-->>Client: 500 Internal Server Error
    end

    Flowintel-->>FlowConn: {case_id}
    FlowConn-->>IncidentSvc: case_id
    IncidentSvc->>IncidentSvc: build link = FLOWINTEL_CASE_URL / case_id
    IncidentSvc-->>API: IncidentResponse(id=case_id, link=link)
    API-->>Client: 200 OK {id, link}
```
