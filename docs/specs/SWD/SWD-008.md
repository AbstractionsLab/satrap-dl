# Analysis endpoint flow

The sequence diagram below depicts the flow of a CTI analysis request, from the initial POST request to the `/analyze/<alert_type>` endpoint to the final response containing the analysis results.

## Successful flow

```mermaid
%% C4 Dynamic diagram — POST /analyze/<alert_type> request lifecycle

sequenceDiagram
    actor RADAR as User
    participant API as api.py (FastAPI)
    participant Registry as AnalyzerRegistry
    participant Analyzer as SuspiciousLoginAnalyzer
    participant RuntimeCfg as runtime_settings.py
    participant MISPMixin as MISPEnrichmentMixin
    participant MISPConn as misp_connector.py
    participant MISP as MISP
    participant Scoring as misp_score.py
    participant FlowConn as flowintel_connector.py
    participant Flowintel as Flowintel

    RADAR->>API: POST /api/v0.1/analyze/<alert_type> {alert_data}

    API->>Registry: analyze(<alert_type>, alert_data)
    Registry->>Registry: lookup and lazy-instantiate <alert_type>Analyzer
    Registry->>Analyzer: validate(alert_data)
     note right of Registry: Data schema validation
    Registry->>Analyzer: analyze(alert_data)

    Analyzer->>RuntimeCfg: load_decipher_runtime_cfg()
    RuntimeCfg-->>Analyzer: RuntimeSettings (enable_misp_search, enable_case_creation, ...)
    note right of RuntimeCfg: mtime-cached YAML, hot-reloads on file change

    alt enable_misp_search = false
        Analyzer-->>API: AnalysisResult(severity=0, misp_available=False)
        API-->>RADAR: 200 AnalysisResult (no enrichment)
    else enable_misp_search = true
        Analyzer->>MISPMixin: search_iocs_in_misp(ioc_mapping)
        MISPMixin->>MISPConn: bulk_search_iocs(ioc_mapping, extra_params)

        loop for each IOC type, with all its values
            MISPConn->>MISP: search(type, value, include_sightings, include_context, extra_params)
            MISP-->>MISPConn: list[MISPAttribute + Event context]
        end

        MISPConn-->>MISPMixin: list[EventData]
        MISPMixin-->>Analyzer: list[EventData]

        Analyzer->>Scoring: score_events(event_data)
        note right of Scoring: Noisy-OR aggregation, Score = Severity x Confidence
        Scoring-->>Analyzer: FinalScoreResult(score, event_results)

        Analyzer->>Analyzer: build AnalysisResult (severity, report, score_breakdown)

        alt enable_case_creation = true
            Analyzer->>FlowConn: create_case_for_scenario(scenario, description, severity)
            FlowConn->>FlowConn: map priority tag from score thresholds
            FlowConn->>Flowintel: POST /cases/create (title, description, tags)
            Flowintel-->>FlowConn: { case_id }
            FlowConn-->>Analyzer: case_id
            Analyzer->>Analyzer: attach case id and link to AnalysisResult
        else enable_case_creation = false
            Analyzer->>Analyzer: log "case creation disabled"
        end

        Analyzer-->>Registry: AnalysisResult
        Registry-->>API: AnalysisResult
        API-->>RADAR: 200 AnalysisResult {analyzed_scenario, severity, report, created_case}
    end
```


## Erroneous paths

Five error scenarios are distinguished by fault origin. Scenarios 1 and 2 terminate before the analyzer is invoked. Scenarios 3 and 4 return 200 with score 0. Scenario 5 returns 200 with no case link.

```mermaid
sequenceDiagram
    actor Client as User
    participant API as API (api.py)
    participant Registry as AnalyzerRegistry
    participant Analyzer as SuspiciousLoginAnalyzer
    participant RuntimeCfg as runtime_settings.py
    participant MISP as MISP (MISPEnrichmentMixin)
    participant Scoring as Scoring Engine
    participant Flowintel as Flowintel

    note over Client,Flowintel: Scenario 1 — unknown alert type
    Client->>API: POST /api/v0.1/analyze/unknown_type {alert_data}
    API->>Registry: analyze("unknown_type", alert_data)
    Registry-->>API: ValueError (unknown alert type)
    API-->>Client: 404 Not Found

    note over Client,Flowintel: Scenario 2 — invalid alert data
    Client->>API: POST /api/v0.1/analyze/valid_alert_type {invalid_data}
    API->>Registry: analyze("valid_alert_type", invalid_data)
    Registry->>Registry: validate data against valid_alert_type schema
    Registry-->>API: ValidationError (field errors)
    API-->>Client: 422 Unprocessable Entity

    note over Client,Flowintel: Scenario 3 — MISP client unavailable
    Client->>API: POST /api/v0.1/analyze/valid_alert_type {alert_data}
    API->>Registry: analyze("valid_alert_type", alert_data)
    Registry->>Analyzer: analyze(alert_data)
    Analyzer->>RuntimeCfg: load_decipher_runtime_cfg()
    RuntimeCfg-->>Analyzer: config (enable_misp_search=True)
    Analyzer->>MISP: search_iocs_in_misp(...)
    MISP-->>Analyzer: UnavailableMISPClientError
    note over Analyzer: misp_available=False, event_data=[]
    Analyzer->>Scoring: score_events([])
    Scoring-->>Analyzer: FinalScoreResult {score=0}
    Analyzer-->>Registry: AnalysisResult {severity=0, misp_available=False}
    Registry-->>API: AnalysisResult
    API-->>Client: 200 OK AnalysisResult {severity=0}

    note over Client,Flowintel: Scenario 4 — MISP enrichment error
    Client->>API: POST /api/v0.1/analyze/valid_alert_type {alert_data}
    API->>Registry: analyze("valid_alert_type", alert_data)
    Registry->>Analyzer: analyze(alert_data)
    Analyzer->>RuntimeCfg: load_decipher_runtime_cfg()
    RuntimeCfg-->>Analyzer: config (enable_misp_search=True)
    Analyzer->>MISP: search_iocs_in_misp(...)
    MISP-->>Analyzer: MISPEnrichmentError
    note over Analyzer: event_data=[], error logged in report
    Analyzer->>Scoring: score_events([])
    Scoring-->>Analyzer: FinalScoreResult {score=0}
    Analyzer-->>Registry: AnalysisResult {severity=0}
    Registry-->>API: AnalysisResult
    API-->>Client: 200 OK AnalysisResult {severity=0}

    note over Client,Flowintel: Scenario 5 — Flowintel case creation failure
    Client->>API: POST /api/v0.1/analyze/valid_alert_type {alert_data}
    API->>Registry: analyze("valid_alert_type", alert_data)
    Registry->>Analyzer: analyze(alert_data)
    Analyzer->>RuntimeCfg: load_decipher_runtime_cfg()
    RuntimeCfg-->>Analyzer: config (enable_case_creation=True)
    Analyzer->>MISP: search_iocs_in_misp(...)
    MISP-->>Analyzer: [EventData list]
    Analyzer->>Scoring: score_events(event_data)
    Scoring-->>Analyzer: FinalScoreResult {score, breakdown}
    Analyzer->>Flowintel: create_case_for_scenario(scenario, description, score)
    Flowintel-->>Analyzer: CaseCreationError
    note over Analyzer: error logged, created_case left empty
    Analyzer-->>Registry: AnalysisResult {severity as computed, no case link}
    Registry-->>API: AnalysisResult
    API-->>Client: 200 OK AnalysisResult {no case link}
```
