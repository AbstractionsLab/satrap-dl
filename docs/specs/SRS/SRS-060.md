# Multi-phase attack identification

As a security analyst, I want DECIPHER to analyze the detection trace that triggered an alert in my detection system so that I can identify potential multi-stage attacks in my infrastructure aligned with well-known threat frameworks (e.g. the Cyber Kill Chain, MITRE ATT&CK).

I want this analysis to be executed by default as part of the analysis of each of the specific threat scenarios whenever the detection trace is given as an alert field.

### Rationale
A single detection rule match rarely proves malicious intent; instead, a chronologically ordered sequence of matches on the same source (e.g. reconnaissance, then credential access, then lateral movement) is a much stronger signal of a coordinated attack, yet, it is costly to reconstruct this attacks manually from raw rule identifiers.

By mapping the detection trace against well-known threat frameworks, DECIPHER surfaces the attack's likely stage(s) alongside the severity score, as a cross-cutting capability applied whenever a detection trace is present, regardless of the threat scenario.
