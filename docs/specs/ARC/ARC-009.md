# REST service: analysis endpoint interaction

This diagram depicts an overview of a successful flow triggered by a request to the analysis endpoint. The general case without a specific threat scenario is depicted.


```mermaid
flowchart TB

    RADAR(["<b>User</b><br/><i>[System or human]</i>"])

    subgraph decipher["DECIPHER Service"]
        direction TB

        subgraph api_layer["API Layer"]
            api["<b>api.py</b><br/>POST /analyze/{alert_type}"]
        end

        subgraph analysis_layer["Analysis Layer"]
            direction LR
            subgraph registry_group["Analyzer Registry"]
                registry["<b>AnalyzerRegistry</b><br/>Route and validate request"]
            end
            subgraph analyzers_group["Analyzers"]
                suspicious["<b>SpecificScenarioAnalyzer</b><br/>analyze(alert)"]
                misp_mixin["<b>MISPEnrichmentMixin</b><br/>search_iocs_in_misp()"]
            end
            registry --> suspicious
            suspicious --> misp_mixin
        end

        subgraph scoring_layer["Scoring Engine"]
            misp_score["<b>misp_score.py</b><br/>score_events(event_data)<br/>Noisy-OR aggregation"]
        end

        subgraph casemanagement_layer["Case Management Layer"]
            flowintel_conn["<b>flowintel_connector.py</b><br/>create_case_for_scenario()"]
        end

        subgraph commons_layer["Commons"]
            misp_connector["<b>misp_connector.py</b><br/>bulk_search_iocs()"]
        end
    end

    MISP(["<b>MISP</b><br/><i>[External]</i>"])
    Flowintel(["<b>Flowintel</b><br/><i>[External]</i>"])

    RADAR            -->|"1. HTTP POST /analyze/{alert_type}<br/>{alert IOCs}"| api
    api              -->|"2. analyze(alert_type, data)"| registry
    registry         -->|"3. validate and dispatch"| suspicious
    suspicious       -->|"4. search_iocs_in_misp(ioc_mapping)"| misp_mixin
    misp_mixin       -->|"5. bulk_search_iocs(ioc_mapping)"| misp_connector
    misp_connector   -->|"6. PyMISP / HTTPS REST"| MISP
    MISP             -->|"7. CTI events, tags, admiralty scores"| misp_connector
    misp_connector   -->|"8. list[EventData]"| misp_mixin
    misp_mixin       -->|"9. list[EventData]"| suspicious
    suspicious       -->|"10. score_events(event_data)"| misp_score
    misp_score       -->|"11. FinalScoreResult"| suspicious
    suspicious       -->|"12. create_case_for_scenario(scenario, description, severity)"| flowintel_conn
    flowintel_conn   -->|"13. PyFlowintel / HTTP REST"| Flowintel
    Flowintel        -->|"14. case_id"| flowintel_conn
    flowintel_conn   -->|"15. case_id"| suspicious
    suspicious       -->|"16. AnalysisResult(severity, report, created_case)"| api
    api              -->|"17. 200 AnalysisResult"| RADAR
```
