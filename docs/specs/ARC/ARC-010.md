# Analysis endpoint: scoring data flow diagram

The diagram below depicts the data flow of the score computation specified in SRS-053. Inputs flow top-to-bottom through two parallel axes, severity and confidence, which are multiplied at event level.
Event scores are then aggregated into a final score via Noisy-OR.

The final result includes the total score with a breakdown of the calculation for analysis purposes.

The partial formulas make use of configurable factors which must be dynamically obtained from a configurable source – e.g., a YAML file. The default parameters depicted in the flowchart are as follows:

| Parameter                | Value                  | Default</br> numeric value |
|--------------------------|-----------------------------|---------|
| Threat level             | undefined                   | 0.0     |
| Threat level             | low                         | 0.25    |
| Threat level             | medium                      | 0.5     |
| Threat level             | high                        | 1.0     |
| Tags multiplier          | Threat-indicating tags present          | 1.5     |
| Analysis stage           | initial                     | 0.2     |
| Analysis stage           | ongoing                     | 0.5     |
| Analysis stage           | completed                   | 1.0     |
| Confidence weight        | analysis                    | 0.5     |
| Confidence weight        | empirical                   | 0.5     |
| Attribute weight         | sightings                   | 0.6     |
| Attribute weight         | admiralty                   | 0.4     |
| Source reliability       | A (completely reliable)     | 1.0     |
| Source reliability       | B (usually reliable)        | 0.8     |
| Source reliability       | C (fairly reliable)         | 0.6     |
| Source reliability       | D (not usually reliable)    | 0.4     |
| Source reliability       | E (unreliable)              | 0.2     |

```mermaid
flowchart TD

    start((start)) --> misp_in
    misp_in --> empty_check{Events list empty?}
    empty_check -->|yes| zero_result["<b>FinalScoreResult</b><br/>score = 0.0<br/>event_results = ()"]
    zero_result --> end_node

    empty_check -->|no| more_events{Unprocessed events?}

    misp_in["<b>MISP Events</b><br/>list[EventData]<br/><br/>threat_level, analysis,<br/>has_threat_tags, admiralty,<br/>list[AttributeData]"]

    more_events -->|yes| sev["<b>Severity</b>= min(1.0, map_value(threat_level) × tags_multiplier)<br/><br/>tags_multiplier = 1.0 + 0.5 × (1 if tags_present,0 if not)"]
    sev --> c_analysis["<b>C_analysis =</b><br/>map_value(analysis stage)"]
    c_analysis --> more_attrs{Unprocessed attributes?}

    more_attrs -->|yes| c_sightings["<b>C_sightings</b><br/>= max(0, 2×(TP+1)/(TP+FP+2) − 1)<br/><br/>TP = positive sightings<br/>FP = false-positive sightings"]
    c_sightings --> c_admiralty["<b>C_admiralty</b><br/>= Sqr(reliability_value × credibility_value)<br/><br/>absent Admiralty tag → value = 0.0"]
    c_admiralty --> c_attr["<b>Att_confidence</b><br/>= w_sightings × C_sightings + w_admiralty × C_admiralty"]
    c_attr --> more_attrs

    more_attrs -->|no| c_evidence["<b>C_evidence</b><br/>= 1 − &prod;(1 − Att_confidence_i)<br/><br/>for all computed Att_confidence values"]
    c_evidence --> confidence["<b>Confidence</b><br/>= w_analysis × C_analysis + w_empirical × C_evidence"]
    confidence --> event_score["<b>Score_event</b><br/>= Severity × Confidence"]
    event_score --> more_events

    more_events -->|no| final_score
    final_score["<b>Final Score</b><br/>= 1 − &prod;(1 − Score_event_i)<br/><br/>for all computed Score_event values<br/>"]
    final_score --> result([End])

    result["<b>FinalScoreResult</b><br/>score = Final score<br/> event_results = score breakdown"]
    result --> end_node([End])
```
