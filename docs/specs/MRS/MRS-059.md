# Standalone incident escalation from an externally-computed triage score

DECIPHER SHALL support case creation in the integrated case management platform driven by an externally-computed triage score, independently of the DECIPHER analysis pipeline, assigning a case priority aligned with the provided score.

### Rationale
To enable external systems and orchestration pipelines to trigger prioritized case escalation using triage scores produced outside of DECIPHER's own analysis workflow, broadening interoperability within the SATRAP-DL ecosystem.
