# Integration with open-source tools for incident handling

DECIPHER SHALL integrate with open-source tools covering three roles in the incident handling
pipeline: a threat detection platform (e.g., a SIEM) as the alert source, a cyber threat
intelligence platform as the enrichment source, and a case management platform as the
escalation target.

### Rationale
1. To support investigations facilitating immediate access to CTI for reacting in an adequate way.
2. To use and enrich the open-source ecosystem in a coherent and interoperable manner, fostering
adoption of SATRAP-DL.

### Acceptance criteria
Successful validation according to the corresponding test case specification
