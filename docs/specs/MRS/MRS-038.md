# Platform-independent API

SATRAP-DL SHALL provide a platform-independent API (e.g., a web-based one such as a REST API) enabling programmatic and human access to the data and services provided by the SATRAP-DL suite.

### Rationale
To provide a programming language-agnostic access point to the analytic services of SATRAP-DL, with human and machine readable specifications and enabling automated orchestration workflows.
