# Automated alert triage and case escalation guided by CTI

DECIPHER SHALL provide a service to automatically assess the severity of incoming security alerts using cyber threat
intelligence.
Additionally, DECIPHER SHALL optionally (as per user configuration) create a case in the integrated case management platform, populated with findings of the analysis and assigned a priority according to the assessed severity.

### Rationale
To reduce alert fatigue by automatically prioritizing incoming security alerts based on CTI analysis and creating pre-populated cases in the case management platform, eliminating manual triage and handoff and accelerating analyst response. Configurable case creation supports diverse operational contexts independently from the underlying assessment capability.
